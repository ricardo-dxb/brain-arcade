# Brain Arcade

Gamified maths and English practice (UK National Curriculum, Year 3 and Year 6 tracks).

- `index.html` is the built, self-contained app served by GitHub Pages.
- `src/` holds the source: question generators (`gens.js`), stretch levels (`hard.js`), science (`sci.js`), personalisation (`pers.js`), app (`app.js`), styles (`app.css`) and `build.py`, which assembles the page.

Progress is saved on each device (browser storage), never in this repository.
